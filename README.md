# Heart Disease Prediction Using Machine Learning

## 📌 Project Overview

This project uses machine learning classification techniques to predict whether a patient is likely to have heart disease based on clinical and health-related features.

The project covers data preprocessing, exploratory data analysis, feature analysis, model building, and evaluation of classification performance.

## 🎯 Objectives

* Analyze patient health and clinical data.
* Perform data cleaning and preprocessing.
* Explore relationships between features and heart disease.
* Train machine learning classification models.
* Evaluate model performance using appropriate classification metrics.
* Identify important features contributing to predictions.

## 🛠️ Technologies Used

* Python
* NumPy
* Pandas

* Jupyter Notebook

9. Model Evaluation
10. Prediction

## 🤖 Machine Learning

The project uses classification algorithms to predict the target variable representing the presence or absence of heart disease.

Models can be evaluated using:

* Accuracy
* Precision
* Recall
* F1-Score
* Confusion Matrix
* ROC-AUC

## 📊 Evaluation

The trained models are evaluated using classification performance metrics to understand their predictive performance and compare model results.

## 🚀 How to Run

### 1. Clone the repository

```bash
git clone https://github.com/Mohammadmazharuddin/heart-disease-prediction.git
```

### 2. Navigate to the project directory

```bash
cd heart-disease-prediction
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Jupyter Notebook

```bash
jupyter notebook
```

Open the project notebook and run the cells sequentially.
